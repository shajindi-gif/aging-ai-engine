# 10分钟产品演示脚本

## 场景：客户演示 / 投资人会议

### 0:00-1:30 开场与定位
- 市场痛点（2.8亿老人、碎片化服务）
- 产品定位（AI原生养老服务基础设施）
- 目标客户（5类画像）

### 1:30-4:00 MVP1：政策数据库与补贴匹配
**操作演示：**
1. 政策数据库浏览：搜索+筛选
2. 查看政策详情：材料清单+办理路径
3. 补贴匹配工具：填写条件→匹配结果
4. 解读匹配分数和置信度
5. 展示政策免责声明

**话术：** "我们的AI Agent分析了40多条政策，3秒钟给出了匹配结果和申请路径。"

### 4:00-6:30 MVP2：陪诊护理CRM
**操作演示：**
1. CRM总览：今日订单、风险预警、待通知家属
2. 老人档案列表→进入详情
3. 健康档案：慢病指标、用药记录、就诊记录
4. 服务记录时间线
5. AI生成服务报告
6. 展示医疗免责声明

**话术：** "一个护理员管理50个老人的档案，以前靠Excel，现在靠AI。"

### 6:30-8:00 MVP3：销售线索库
**操作演示：**
1. Pipeline看板
2. 机构数字化评分
3. 筛选目标机构
4. 导出线索

### 8:00-9:00 Agent工作台
**操作演示：**
1. 选择风险预警Agent
2. 输入老人ID
3. 查看输出：风险等级+建议措施
4. 解释置信度和人工复核机制

### 9:00-10:00 总结与Q&A
- 技术亮点回顾
- 定价方案
- 下一步计划
