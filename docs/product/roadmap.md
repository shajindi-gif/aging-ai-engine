# 产品路线图

## Phase 1: MVP + Demo（M1-M3）✅ 当前阶段
- Next.js 官网与 SaaS Demo
- 18个数据实体 + Mock 数据
- 22条 API 路由
- 6个 Agent Mock 函数
- SDK + MCP Server + Chrome 插件初版
- 40+ 政策、30+ 老人、80+ 订单、80+ 机构 Mock 数据

## Phase 2: 真实数据 + LLM（M4-M6）
- 接入 Postgres/Supabase 数据库
- 用户注册与登录（JWT/OAuth）
- 接入 LLM API（OpenAI/通义千问/智谱）
- Agent 从 Mock 升级为真实推理
- 政策数据爬取 Pipeline
- 机构数据采集 Pipeline
- 角色权限管理

## Phase 3: 移动端 + 支付（M7-M9）
- 微信小程序上线
- 移动端响应式优化
- 支付系统（微信支付/支付宝）
- 飞书/钉钉 Bot MVP
- 运营数据看板
- A/B 测试框架

## Phase 4: 平台化（M10-M12）
- Tauri 桌面端
- API 市场（第三方 Agent 接入）
- 多租户架构
- 数据导出与分析
- 行业报告自动生成

## 长期愿景（Year 2-3）
- 覆盖全国 300+ 城市政策
- 10万+ 养老机构数据
- 成为中国银发经济最大数据平台
- AI Agent 覆盖养老服务全场景
- 国际化（东南亚、日本养老市场）
