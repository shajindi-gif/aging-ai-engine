# MVP 范围定义

## Phase 1 范围（当前版本 v0.2.0）

### 包含
- 官网（首页、产品、定价、合规、联系、演示、文档）
- 银发经济政策数据库（40+政策、10+城市）
- 养老补贴智能匹配工具
- 陪诊护理服务CRM（老人档案、订单、服务记录）
- 老人健康档案详情
- 养老机构销售线索库（80+机构）
- AI Agent 工作台（6个Agent）
- Mock API（22条）
- SDK 客户端库
- MCP Server（12个工具）
- Chrome 插件（Web Clipper）
- 25+文档文件

### 不包含（后续版本）
- 真实数据库（Postgres/Supabase）
- 用户认证与权限管理
- LLM 驱动的真实 Agent 推理
- 支付系统
- 微信小程序
- 移动端 App
- 飞书/钉钉 Bot
- Tauri 桌面端

## 功能优先级矩阵

### P0（必须有）
- 政策数据库浏览与搜索
- 补贴匹配工具
- 老人档案管理
- 订单管理
- 服务记录
- 风险事件记录
- 家属通知状态
- 医疗/政策免责声明

### P1（应该有）
- Agent 工作台
- 销售线索库
- 数字化成熟度评分
- SDK / MCP Server
- Chrome 插件

### P2（可以有）
- 运营日报
- 数据导出
- 多语言支持
- 深色模式

## 用户旅程

### 旅程1：子女为父母查政策
1. 打开官网首页 → 了解产品
2. 进入补贴匹配工具 → 填写父母条件
3. 查看匹配结果 → 了解可申请政策
4. 查看政策详情 → 获取材料清单
5. 按办理路径申请

### 旅程2：陪诊公司管理订单
1. 登录CRM后台 → 查看今日订单
2. 处理待确认订单 → 分配服务人员
3. 查看服务记录 → 确认完成
4. 处理风险事件 → 通知家属
5. AI生成服务报告 → 发送给家属

### 旅程3：养老SaaS企业找客户
1. 进入销售线索库 → 筛选目标区域
2. 查看机构数字化评分 → 识别低数字化高意向机构
3. 查看建议产品 → 了解切入策略
4. 导出线索 → 开始跟进

## 成功指标
- 演示完成率 > 90%
- 政策匹配准确率 > 85%
- API响应时间 < 500ms
- 页面加载时间 < 2s
