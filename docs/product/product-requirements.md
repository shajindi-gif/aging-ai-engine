# 衍策银龄 AI — 产品需求文档 (PRD)

## 产品愿景与定位

衍策银龄 AI 是中国银发经济 AI 原生服务基础设施，面向社区居家养老、陪诊护理、养老机构运营、补贴匹配和银发经济数据服务的智能工作台。

### 核心价值主张
用 AI Agent、RAG 知识库和 SaaS 工作流，帮助老人家庭、陪诊护理公司、社区服务站、养老机构和银发经济企业，把养老服务从微信群、Excel 和纸质档案升级为可追踪、可提醒、可复盘、可增长的数字化服务系统。

## 目标用户画像

### 画像1：老人家庭和中青年子女
- 年龄：35-55岁子女为父母寻找养老服务
- 痛点：不了解养老补贴政策、找不到可信服务商、无法远程关注父母健康
- 需求：政策匹配、服务预约、健康报告

### 画像2：陪诊公司和护理服务团队
- 规模：5-50人团队
- 痛点：订单管理混乱（微信群+Excel）、服务记录缺失、家属沟通低效
- 需求：订单CRM、服务记录、家属报告、排班管理

### 画像3：养老机构和社区养老服务站
- 规模：30-500床位
- 痛点：档案管理纸质化、风险事件难追溯、运营数据缺失
- 需求：数字档案、风险预警、运营日报、政策匹配

### 画像4：适老化改造与智慧养老企业
- 痛点：找不到目标客户、不了解机构数字化水平、销售线索匮乏
- 需求：机构线索库、数字化成熟度评分、采购意向预测

### 画像5：政府、园区、街道和产业服务平台
- 痛点：养老服务监管数据缺失、政策落地效果难评估
- 需求：区域政策库、服务监管看板、机构画像

## 三大 MVP

### MVP 1：银发经济政策数据库与补贴匹配工具
- 覆盖10+城市、40+条政策
- 智能匹配引擎：输入老人条件，输出可申请政策清单
- 材料清单生成器
- 办理路径指引

### MVP 2：陪诊护理服务 CRM
- 老人客户档案管理
- 服务订单全流程管理
- 服务记录时间线
- 家属通知与周报
- 风险事件预警
- AI生成服务报告

### MVP 3：养老机构销售线索库
- 80+养老机构数据
- 数字化成熟度评分（L1-L5）
- 采购意向评分
- 跟进状态管理
- 线索导出

## Agent 系统需求

### 政策匹配 Agent
- 输入：地区、年龄、居住状态、护理等级、失能状态、收入水平、申请主体
- 输出：匹配政策列表、匹配分数、资格原因、缺失材料、下一步路径
- 置信度阈值：0.7
- 人工复核：匹配分数低于0.75时触发

### 家属报告 Agent
- 输入：老人ID、时间范围
- 输出：健康摘要、近期服务记录、用药提醒、复诊任务、风险警报、家属友好摘要
- 人工复核：始终需要

### 机构画像 Agent / 风险预警 Agent / 服务总结 Agent / 销售跟进 Agent
（详见 agent-workflows.md）

## 非功能需求
- 性能：页面加载 < 2s，API响应 < 500ms
- 安全：健康数据加密存储，API鉴权
- 合规：所有健康页面含医疗免责声明，所有政策页面含政策免责声明
- 可用性：99.9% uptime
- 响应式：适配PC、平板、手机
