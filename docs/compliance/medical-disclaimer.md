# 医疗免责声明

## 完整声明文本

**本系统仅用于健康信息整理、服务记录和风险提示，不替代医生诊断、治疗建议或医疗决策。具体诊疗请咨询执业医生。**

## 使用场景
以下页面和功能必须展示此声明：
- 老人健康档案页（/elders/[id]）
- 陪诊护理CRM（/care-crm）
- 健康摘要Agent输出
- 家属报告Agent输出
- 风险预警Agent输出
- 慢病指标记录
- 用药提醒

## 展示要求
- 红色背景（#fef2f2），红色边框（#fecaca），深红文字（#991b1b）
- 位于页面顶部或功能入口处
- 字体不小于14px
- 不可折叠或隐藏

## 实现指南
```html
<div class="yc-disclaimer yc-disclaimer-medical">
  本系统仅用于健康信息整理、服务记录和风险提示，不替代医生诊断、治疗建议或医疗决策。具体诊疗请咨询执业医生。
</div>
```

## 审核流程
- 任何涉及健康数据的功能上线前必须经法务审核
- 声明文本修改需经法律顾问确认
