# 免费工具增长漏斗

## 转化漏斗设计

参考高访问 AI 工具站的增长模型，为所有免费工具和模板页设计统一转化漏斗。

## 用户状态

| 状态 | 能力 | 转化目标 |
|------|------|----------|
| anonymous | 游客可试用基础工具，查看 60% 结果 | 引导注册 |
| registered | 注册用户可保存结果、查看完整报告 | 引导试用 |
| trial | 试用用户可使用更多模板和工具 | 引导付费 |
| paid | 付费用户可批量管理、导出、调用 Agent、使用 API | 续费/升级 |

## 漏斗流程

```
访客进入页面
→ 输入简单信息
→ 免费生成初步结果
→ 展示 60% 结果
→ 提示注册可保存完整结果
→ 提示开通专业版可导出 PDF / 生成完整报告 / 批量管理
→ 引导进入 SaaS 后台或预约演示
```

## 每个工具页必备元素

1. SEO 标题和描述
2. 一句话功能说明
3. 输入表单
4. 结构化输出（60% 可见）
5. 免责声明（政策类/健康类）
6. 相关工具推荐（3个）
7. 转化 CTA：注册保存 / 生成完整报告 / 预约演示 / 开通专业版
