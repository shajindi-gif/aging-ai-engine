参考 Perplexity（搜索即答案）和 ChatGPT（产品即入口）模式，通过免费 AI 工具建立养老服务领域的搜索流量入口。

## 每个工具页必备元素

1. **SEO 标题** — 包含核心关键词
2. **一句话解释** — 说明工具价值
3. **输入表单** — 5-6 个字段，极简设计
4. **结构化输出** — 展示 60% 结果
5. **免责声明** — 政策类/健康类必须有
6. **相关工具推荐** — 3 个关联工具
7. **转化 CTA** — 注册保存/完整报告/预约演示/升级专业版

## 统一转化漏斗

```
进入工具页 → 填写表单 → 生成结果 → 查看 60% → 注册看完整 → 升级专业版 → SaaS 后台
```
