# 模板库增长策略

## 概述

参考 Gamma / Canva / Notion AI 的模板增长模式，建立养老服务垂直领域模板库。

## 模板分类（5 大类 35 个模板）

### 家属沟通模板（7 个）
陪诊后家属通知、护理服务完成通知、异常风险提醒、复诊提醒、用药提醒、家属周报、紧急事件通知。

### 服务记录模板（7 个）
陪诊记录、上门护理记录、康复陪护记录、生活照料记录、术后照护记录、助浴服务记录、助餐服务记录。

### 政策申报模板（7 个）
高龄津贴材料清单、长护险申请材料清单、适老化改造申请材料清单、社区助餐补贴材料清单、养老机构运营补贴材料清单、失能老人照护补贴材料清单、护理员培训补贴材料清单。

### 机构运营模板（7 个）
养老机构运营日报、社区养老站周报、陪诊公司订单日报、护理团队服务复盘、风险事件复盘、护理人员排班模板、服务质量月报。

### 销售线索模板（7 个）
养老机构画像、适老化改造客户画像、智慧养老硬件销售话术、护理设备客户跟进计划、银发经济B2B销售邮件、销售方案大纲、展会推介话术。

## 增长机制

1. 模板详情页展示输出样例 → 用户想使用 → 注册
2. 免费版每月 3 次模板使用 → 付费版无限使用
3. 模板分享 → 社交传播 → 新用户获取
4. 模板 SEO → 搜索引擎流量
