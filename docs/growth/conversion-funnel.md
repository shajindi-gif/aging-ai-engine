# 衍策银龄 AI — 转化漏斗设计

---

## 用户状态定义

| 状态 | 标识 | 能力 | 转化目标 |
|------|------|------|----------|
| anonymous | 游客 | 试用基础工具，查看 60% 结果 | 引导注册 |
| registered | 注册用户 | 保存结果，查看完整报告 | 引导试用 |
| trial | 试用用户 | 更多模板，批量功能 | 引导付费 |
| paid | 付费用户 | 全部功能，API，Agent | 续费/升级 |
| enterprise | 企业客户 | 定制部署，SSO，SLA | 扩展 |

## 九条转化路径

### 1. 游客路径

```
搜索引擎/社交媒体/直接访问
→ 首页 / 工具页 / 模板页 / 城市 SEO 页
→ 看到工具/模板/内容
→ 输入信息试用
→ 看到 60% 结果
→ 注册查看完整结果
```

**关键页面**：/, /tools/*, /templates/*, /city/*, /resources/*

**转化率目标**：15-25%（访问→试用）

### 2. 免费工具路径

```
进入免费工具页
→ 阅读工具说明
→ 填写输入表单
→ 点击"生成结果"
→ 查看 AI 分析（60% 展示）
→ 提示"注册查看完整结果"
→ 注册
→ 查看完整结果
→ 提示"开通专业版可导出 PDF / 批量管理"
→ 引导到定价页
```

**关键页面**：/tools/[tool-slug]

**转化率目标**：30-40%（试用→看到结果），8-12%（看到结果→注册）

### 3. 注册路径

```
点击"免费注册"
→ 填写邮箱/手机号
→ 验证
→ 进入 SaaS 后台引导流程
→ 引导创建第一个老人档案
→ 引导使用第一个 Agent
→ 引导查看模板库
→ 提示"升级到专业版解锁更多功能"
```

**关键页面**：/login, /dashboard

**转化率目标**：20-30%（注册→完成引导），5-10%（引导→试用）

### 4. 试用路径

```
注册用户
→ 使用免费工具（每月限额）
→ 使用模板（每月 3 次）
→ 达到限额
→ 提示"开通 14 天专业版试用"
→ 开始试用
→ 体验全部功能
→ 试用到期
→ 选择付费方案
```

**关键页面**：/dashboard/*, /tools/*, /templates/*

**转化率目标**：15-25%（达到限额→开始试用），20-35%（试用→付费）

### 5. 预约演示路径

```
企业客户/政府客户
→ 首页/解决方案页/定价页
→ 点击"预约演示"
→ 填写表单（公司/角色/需求/时间）
→ 销售团队跟进
→ 线上演示（30-60 分钟）
→ 定制方案报价
→ 合同签订
```

**关键页面**：/demo, /solutions/*, /contact

**转化率目标**：3-5%（访问→预约），30-50%（演示→签约）

### 6. 付费路径

```
试用用户/高频用户
→ 达到免费限额
→ 进入定价页
→ 对比方案
→ 选择方案
→ 支付（月付/年付）
→ 解锁全部功能
→ 续费/升级
```

**关键页面**：/pricing, /dashboard

**转化率目标**：5-10%（试用→付费），80%+（月付→续费）

### 7. B2B 客户路径（陪诊公司/护理公司/养老机构）

```
行业展会/搜索引擎/行业媒体
→ 解决方案页（/solutions/medical-companion-company 等）
→ 阅读痛点→解决方案→工作流
→ 查看 Demo 截图
→ 点击"预约演示"或"申请试用"
→ 销售跟进
→ 定制演示
→ 试用（30 天）
→ 合同签订
→ 实施上线
→ 续费/扩展
```

**关键页面**：/solutions/*, /demo, /pricing

**转化率目标**：2-5%（解决方案页→预约），40-60%（试用→签约）

### 8. 政府/园区客户路径

```
政府招标/产业园区/行业论坛
→ /solutions/government-park
→ 阅读区域数据平台方案
→ 点击"联系合作"
→ BD 团队跟进
→ 需求调研（1-2 周）
→ 定制方案（2-4 周）
→ 项目招标/直接签约
→ 实施部署（1-3 月）
→ 运营服务
```

**关键页面**：/solutions/government-park, /contact

**转化率目标**：1-3%（方案页→联系），50-70%（调研→签约）

### 9. 开发者路径

```
GitHub/Hacker News/技术社区
→ /developers
→ 阅读 API 文档
→ 安装 SDK（npm install）
→ 运行示例代码
→ 申请 API 试用 Key
→ 集成到自有产品
→ 达到免费额度
→ 升级为付费 API 用户
```

**关键页面**：/developers, /docs

**转化率目标**：10-20%（文档→安装），5-10%（试用→付费 API）

## 漏斗优化策略

### 减少摩擦

- 免费工具无需注册即可试用
- 输入表单字段最少化（5-6 个字段）
- 结果即时生成（< 2 秒）
- 注册流程简化（邮箱或手机号一键注册）

### 增加价值感知

- 展示 60% 结果让用户看到价值
- 输出样例展示在模板详情页
- 社会证明（Demo 数据标注）
- 免费工具和模板的 SEO 标题强调利益点

### 自然升级

- 限额提示（"本月已使用 3/3 次免费工具"）
- 结果完整度提示（"注册查看完整报告"）
- 功能对比表（免费版 vs 专业版 vs 企业版）
- 案例驱动（"XX 公司使用专业版后效率提升 60%"）
