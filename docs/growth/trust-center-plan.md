# 衍策银龄 AI — 信任中心规划

---

## 策略定位

参考 Claude / Anthropic 的企业可信页面模式，将信任与安全作为产品核心卖点，而非附属页面。在中国养老服务场景中，医疗边界和数据隐私是建立企业客户信任的关键。

## 四大分类 · 12 个信任项

### 医疗边界（3 项）

| 信任项 | 说明 | 页面展示 |
|--------|------|----------|
| 不替代医生诊断 | 不输出医疗诊断或治疗建议 | /trust + 所有健康相关页面 |
| 人工复核机制 | AI 结果支持人工复核，高风险强制确认 | /trust + Agent 输出 |
| 医疗边界声明 | 完整声明文本 | /trust + 所有健康相关页面 |

**完整声明文本**：

> 本系统仅用于健康信息整理、服务记录和风险提示，不替代医生诊断、治疗建议或医疗决策。具体诊疗请咨询执业医生。

### 隐私保护（3 项）

| 信任项 | 说明 | 实现方式 |
|--------|------|----------|
| 用户授权同意 | 健康数据仅在明确授权后采集 | 授权弹窗 + 可随时撤回 |
| 数据最小化 | 仅采集服务必需的最少数据 | 数据分类 + 采集审查 |
| 不用于营销 | 健康/家庭数据绝不用于商业营销 | 技术隔离 + 合同约束 |

### 数据安全（4 项）

| 信任项 | 说明 | 实现方式 |
|--------|------|----------|
| 数据脱敏 | 自动脱敏姓名/手机/身份证 | 脱敏算法 + 展示层脱敏 |
| 企业级权限 | 按角色设置访问权限 | RBAC + 最小权限 |
| 审计日志 | 记录所有数据访问和操作 | 操作日志 + 追溯查询 |
| 导出和删除 | 用户可导出全部数据，注销后 30 天删除 | 数据导出 API + 删除流程 |

### 合规透明（2 项）

| 信任项 | 说明 | 实现方式 |
|--------|------|----------|
| 政策匹配免责声明 | 结果仅供参考，以主管部门审核为准 | 所有政策相关页面 |
| AI 置信度透明 | Agent 输出附带置信度和推理依据 | 所有 Agent 输出 |

**完整免责声明文本**：

> 政策匹配结果仅供参考，具体资格、材料和办理结果以当地主管部门、街道社区或经办机构最终审核为准。

## /trust 页面结构

1. 首屏：信任中心标题 + 一句话承诺
2. 四大分类 tab/分区展示
3. 完整医疗边界声明（红色背景框）
4. 完整政策免责声明（黄色背景框）
5. 企业级安全特性（虚线框，标注"规划中"）
6. 底部 CTA：联系安全团队 / 下载报告安全白皮书
