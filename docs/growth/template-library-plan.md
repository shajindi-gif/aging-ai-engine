## 模板详情页结构

每个模板详情页（/templates/[slug]）包含：

1. **模板名称** — SEO 标题
2. **适用对象** — 目标用户
3. **使用场景** — 何时使用
4. **输入字段** — 需要填写的信息
5. **输出样例** — 生成的结果预览
6. **一键生成** — 填写信息生成结果
7. **保存到后台** — 注册保存
8. **升级 CTA** — 专业版解锁全部模板

## 增长机制

| 机制 | 说明 |
|------|------|
| SEO 获客 | 35 个模板详情页 = 35 个可索引页面 |
| 预览转化 | 输出样例让用户看到价值 → 注册 |
| 限额升级 | 免费版每月 3 次 → 付费版无限 |
| 社交传播 | 模板结果分享 → 新用户获取 |
| 交叉推荐 | 相关模板推荐 → 增加页面浏览 |
