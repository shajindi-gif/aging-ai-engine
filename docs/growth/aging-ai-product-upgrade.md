# 衍策银龄 AI 产品结构升级方案

> 将全球高访问 AI 网站的成功模式迁移到中国老龄化与银发经济场景。

---

## 一、首页改造：从宣传型到工具型

### 借鉴：ChatGPT / Gemini 首页

| 原首页（v0.2） | 新首页（v0.3） |
|----------------|----------------|
| Hero 区域是品牌口号 | Hero 区域是 AI 输入框 |
| 产品介绍为主 | 工具入口为主 |
| 单一 CTA | 双 CTA（补贴匹配 + 家属报告） |
| 无社会证明 | 数据条（标注 Demo） |
| 无免费工具入口 | 6 个工具预览卡片 |

### 首页结构

1. **AI 输入框**：placeholder 引导用户输入老人信息，一键匹配补贴政策
2. **双 CTA**：养老补贴匹配 Agent + 家属照护报告生成
3. **三大产品入口**：政策数据库、护理 CRM、机构线索库
4. **六大场景入口**：按用户身份引导（家庭/陪诊公司/社区站/机构/改造企业/政府园区）
5. **社会证明**：数据指标条（标注 Demo 数据）
6. **免费工具矩阵**：6 个工具预览
7. **模板 + 资源入口**：双卡片引导到模板库和资源中心
8. **开发者入口**：暗色卡片突出 API/SDK
9. **免责声明**：政策 + 医疗双免责
10. **统一 CTA**：免费试用 / 预约演示 / 查看定价

## 二、免费工具矩阵

### 借鉴：Perplexity 搜索 + Gamma 模板驱动 + ChatGPT 即时体验

10 个免费 AI 工具，每个工具独立 SEO 页面，具备：

- SEO 标题和 meta description
- 输入表单（5-6 个字段）
- 结构化输出（展示 60% 结果）
- 注册墙（提示注册查看完整结果）
- 免责声明（政策类/健康类）
- 相关工具推荐（3 个）
- 转化 CTA（注册/升级/预约演示）

### 工具列表

| 工具 | 借鉴模式 | SEO 关键词 |
|------|----------|-----------|
| 养老补贴资格初筛 | Perplexity 搜索即答案 | 养老补贴查询、高龄津贴申请 |
| 家属照护报告生成器 | Gamma 输入即成品 | 老人健康周报、家属报告 |
| 陪诊记录总结器 | 垂直Agent 工作流 | 陪诊记录模板、就诊总结 |
| 居家照护计划生成器 | Gamma 模板驱动 | 居家护理方案、照护计划 |
| 用药提醒计划生成器 | 垂直Agent 自动化 | 老人用药管理、用药提醒 |
| 复诊提醒生成器 | 垂直Agent 自动化 | 复诊提醒、就诊跟进 |
| 老人照护风险初筛 | 垂直Agent 风险评估 | 老人跌倒风险、照护安全 |
| 适老化改造清单生成器 | Gamma 输入即成品 | 适老化改造、居家改造补贴 |
| 养老机构线索评分工具 | 垂直Agent B2B | 养老机构评估、B2B线索 |
| 政策申报材料清单生成器 | Perplexity 结构化结果 | 补贴申请材料、政策申报 |

## 三、模板库

### 借鉴：Gamma / Canva / Notion AI 模板增长

35 个养老服务模板，覆盖 5 大类别。每个模板详情页包含：模板名称、适用对象、使用场景、输入字段、输出样例、一键生成按钮、保存到后台、升级 CTA。

### 模板分类

| 类别 | 数量 | 核心模板 |
|------|------|----------|
| 家属沟通 | 7 | 陪诊通知、护理完成通知、风险提醒、复诊提醒、用药提醒、周报、紧急通知 |
| 服务记录 | 7 | 陪诊记录、上门护理、康复陪护、生活照料、术后照护、助浴、助餐 |
| 政策申报 | 7 | 高龄津贴、长护险、适老化改造、社区助餐、机构运营补贴、失能照护、护理员培训 |
| 机构运营 | 7 | 运营日报、社区周报、订单日报、团队复盘、风险复盘、排班、质量月报 |
| 销售线索 | 7 | 机构画像、改造客户画像、硬件销售话术、跟进计划、B2B邮件、方案大纲、展会话术 |

### 增长机制

- 模板详情页 → 输出样例吸引 → 注册使用 → 免费每月 3 次 → 付费无限
- 模板 SEO → 搜索引擎流量 → 新用户获取
- 模板分享 → 社交传播
