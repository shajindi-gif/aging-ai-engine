## 一、项目名称与愿景

**项目名称**：衍策银龄 AI（Aging AI Engine）

**运营主体**：上海衍策引擎人工智能科技有限公司

**愿景**：成为中国老龄化社会最核心的 AI 基础设施——连接养老服务供需两端，用数据和智能重新定义养老体验。

**使命**：通过 AI 技术降低养老服务的信息化门槛，让政策红利精准触达每一位需要帮助的老人，让养老服务从「经验驱动」升级为「数据驱动」。

### 2.2 养老服务市场痛点

1. **信息不对称严重** — 3000+ 养老政策分散在各级政府部门，90% 以上的老人和家属不知道自己能享受哪些补贴
2. **数字化程度低** — 80% 以上的中小型养老机构仍在使用纸质记录和 Excel 管理
3. **服务标准化不足** — 陪诊、护理等服务质量参差不齐，缺乏数据化评估体系
4. **供需匹配低效** — 养老机构获客成本高、家属选择难度大
5. **健康数据碎片化** — 就诊记录、用药信息、护理记录分散在不同系统中

### 2.3 政策红利

- **《「十四五」国家老龄事业发展和养老服务体系规划》** — 明确推进智慧养老
- **《关于发展银发经济增进老年人福祉的意见》** — 首次以国务院名义定义银发经济
- **长期护理保险试点** — 已在 49 个城市试点，覆盖 1.7 亿人
- **数字中国战略** — 养老服务数字化列为重点民生工程

## 五、三大商业 MVP

### MVP1: 政策数据与补贴匹配引擎

**目标客户**：社区养老服务站、养老咨询机构

**核心功能**：
- 全国 3000+ 养老政策结构化数据库
- AI 智能匹配引擎（年龄/地区/护理等级/残疾等级/特殊条件）
- 匹配分数 + 申请路径 + 预估金额输出

**商业模式**：数据库订阅制（按年/按机构）

**验证指标**：匹配准确率 > 85%、政策更新频率 < 7 天

### MVP2: 护理 CRM 与健康档案

**目标客户**：陪诊护理公司、社区护理站

**核心功能**：
- 7 类服务订单全流程管理（陪诊/护理/康复/陪伴/助浴/助餐/保洁）
- 老人健康画像（慢性病/用药/就诊/风险标记）
- 风险事件追踪与闭环管理
- AI 自动生成服务报告

**商业模式**：SaaS 订阅（按坐席/按订单量）

**验证指标**：订单处理效率提升 60%、风险事件发现率 > 90%

### MVP3: 销售线索与 AI Agent 工作台

**目标客户**：养老 SaaS 企业、养老设备厂商

**核心功能**：
- 养老机构线索挖掘与评分
- 数字化成熟度 5 维度评估（L1-L5）
- 6 大 AI Agent 统一工作台
- 开放 API / SDK 集成

**商业模式**：线索订阅 + API 调用计费

**验证指标**：线索转化率 > 15%、Agent 任务成功率 > 95%

## 七、技术架构（简述）

### 前端

- **Next.js 16** + React 19 + TypeScript — 现代全栈框架，支持 SSR/SSG
- **Tailwind CSS v4** — 原子化样式系统，高效开发
- **App Router** — 服务端组件优先，性能优化

### 后端

- **API Routes** — 6 个 RESTful 端点，支持 CORS
- **AI Agent 引擎** — 6 大智能体（政策匹配/健康摘要/服务报告/风险评估/机构推荐/家属报告）
- **Prisma ORM** — 类型安全的数据库访问（PostgreSQL）

### 开放生态

- **@aging-ai/sdk** — TypeScript 客户端库
- **MCP Server** — Model Context Protocol，AI 助手原生集成
- **Chrome Extension** — 浏览器端服务能力

### 基础设施

- **Vercel** — 全球 CDN 部署，自动扩缩
- **PostgreSQL** — 可靠的关系型数据存储
- **CI/CD** — 自动化构建与部署

## 十、数据壁垒与护城河

### 数据飞轮

```
更多用户 → 更多服务数据 → 更好的 AI 模型
    ↑                                ↓
更好的服务 ← 更精准的匹配 ← 更丰富的数据
```

### 护城河层次

1. **政策数据壁垒** — 持续维护全国 3000+ 养老政策结构化数据，竞品冷启动成本高
2. **行业模型壁垒** — 养老领域专用的风险评估、匹配算法，依赖大量真实数据训练
3. **网络效应** — 养老机构、护理公司、家属三方网络，越多用户价值越大
4. **切换成本** — 客户在平台上积累的健康档案、服务记录难以迁移
5. **生态锁定** — SDK/API 被集成后，客户替换成本极高
