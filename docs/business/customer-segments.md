# 客户细分

## Segment 1：老人家庭和中青年子女（B2C）
- 市场规模：2.8亿60岁以上老人 × 2-3个子女 = 6-8亿潜在用户
- 付费意愿：低（免费增值模式）
- 获客渠道：搜索引擎、社交媒体、社区推广
- 转化路径：免费政策查询 → 注册 → 付费深度匹配
- 预期占比：用户量80%，收入10%

## Segment 2：陪诊公司和护理服务团队（B2B SMB）
- 市场规模：全国约5万家陪诊/护理公司
- 付费意愿：中等（¥980-2980/月）
- 获客渠道：行业展会、百度SEM、老客户推荐
- 转化路径：Demo → 试用 → 订阅
- 销售周期：2-4周
- 预期占比：用户量15%，收入40%

## Segment 3：养老机构和社区养老服务站（B2B Mid-market）
- 市场规模：全国约4万家养老机构 + 30万社区站
- 付费意愿：中高（¥2980/月 或 定制）
- 获客渠道：政府采购、行业协会、直销
- 转化路径：需求调研 → 方案 → 试点 → 签约
- 销售周期：1-3个月
- 预期占比：用户量4%，收入35%

## Segment 4：适老化改造与智慧养老企业（B2B Enterprise）
- 市场规模：约3000家相关企业
- 付费意愿：高（数据库订阅 ¥9800-19800/年）
- 获客渠道：行业报告、展会、BD
- 预期占比：用户量0.5%，收入10%

## Segment 5：政府、园区、街道（B2G）
- 市场规模：全国约4万个乡镇街道
- 付费意愿：项目制（¥10-100万/项目）
- 获客渠道：政府采购、关系营销
- 销售周期：3-12个月
- 预期占比：用户量0.5%，收入5%
