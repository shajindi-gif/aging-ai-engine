# Go-to-Market 策略

## Phase 1：种子期（M1-M6）

### 获客策略
1. **内容营销**：养老政策解读、行业报告、公众号/知乎
2. **行业展会**：老博会、智慧养老峰会、健康产业展
3. **直销**：针对上海陪诊公司和养老机构，面对面Demo
4. **合作伙伴**：与养老产业联盟、行业协会合作

### 关键动作
- 完成产品Demo（当前）
- 获取首批10个付费客户
- 建立3个标杆案例
- 参加2-3个行业展会

### 预期指标
- 注册用户：500
- 付费客户：10
- MRR：¥20,000

## Phase 2：增长期（M7-M18）

### 获客策略
1. **SEM/SEO**：养老政策、陪诊系统等关键词
2. **渠道合作**：养老设备经销商、信息化集成商
3. **政府采购**：进入政府采购目录
4. **行业媒体**：养老行业垂直媒体投放

### 关键动作
- 覆盖5个城市
- 建立渠道伙伴网络
- 获取100个付费客户
- 完成A轮融资

### 预期指标
- 付费客户：100
- MRR：¥200,000
- ARR：¥2,400,000

## Phase 3：规模化（M19-M36）

### 获客策略
1. **平台效应**：API市场、第三方Agent
2. **品牌效应**：行业报告、白皮书、峰会演讲
3. **国际化**：东南亚、日本养老市场

### 预期指标
- 付费客户：1000+
- ARR：¥20,000,000+
