# 评委/投资人 Q&A 预备

## 市场类（5题）

### Q1: 市场规模有多大？
**A:** 中国60岁以上老人2.8亿（2025），银发经济规模超7万亿。养老服务市场约5000亿，其中信息化和AI服务约500亿，年增长率20%+。

### Q2: 政策支持力度如何？
**A:** 国家十四五规划、银发经济意见、智慧养老行动计划三重政策加持。各地方出台养老服务补贴，长护险试点扩至49城。

### Q3: 竞争格局怎样？
**A:** 现有玩家多为传统信息化企业，AI原生产品极少。我们的差异化在于AI Agent+数据资产+多端分发。

### Q4: 行业壁垒在哪？
**A:** 数据壁垒（政策库+机构库）、行业know-how（养老服务流程理解）、网络效应（越多客户越多数据越好用）。

### Q5: 增长趋势？
**A:** 中国每年新增1000万60岁以上老人。养老服务数字化渗透率<5%，增长空间巨大。

## 产品类（5题）

### Q6: 技术架构是什么？
**A:** Next.js + TypeScript + Tailwind + Prisma。Agent系统支持接入OpenAI/通义千问/智谱。MCP协议兼容Claude等AI助手。

### Q7: Agent可靠性如何保证？
**A:** 每个Agent有置信度阈值，低于阈值自动触发人工复核。所有输出包含来源引用和免责声明。

### Q8: 数据安全怎么保障？
**A:** 健康数据加密存储，API鉴权，数据脱敏展示。支持私有化部署。符合个人信息保护法和数据安全法。

### Q9: 扩展性如何？
**A:** 18实体数据模型可扩展到100+。Agent系统可插拔新增。SDK支持自定义扩展。

### Q10: 用户体验如何？
**A:** 响应式设计，支持PC/平板/手机。操作流程优化到3步完成核心任务。中文界面，适老化大字体。

## 商业类（5题）

### Q11: 盈利模式是什么？
**A:** SaaS订阅+数据库订阅+API计费+定制部署。核心收入来自SaaS订阅（60%）和数据库订阅（25%）。

### Q12: 获客成本多少？
**A:** B2B SMB约¥2000-5000，B2G约¥2-5万。LTV/CAC > 5x，健康可持续。

### Q13: 客单价多少？
**A:** SaaS ¥980-2980/月，数据库 ¥4980-19800/年，定制 ¥5-20万/项目。

### Q14: 复购率如何？
**A:** SaaS行业基准85%+，养老服务粘性更强（数据迁移成本高），预期90%+。

### Q15: 规模化路径？
**A:** 先上海打透 → 扩展5个一线城市 → 全国覆盖。先陪诊公司 → 养老机构 → 政府。

## 团队类（3题）

### Q16: 团队核心优势？
**A:** AI技术+产业互联网+养老行业三重背景。

### Q17: 招聘计划？
**A:** 6个月内：+2全栈、+1数据工程、+1养老行业BD。

### Q18: 顾问资源？
**A:** 养老行业协会、三甲医院老年科、头部养老企业高管。

## 风险类（2题）

### Q19: 最大风险是什么？
**A:** 市场推广速度。养老行业数字化意识较弱，需要教育市场。对策：从最痛的陪诊公司切入。

### Q20: 退出策略？
**A:** 路径1：被大型养老/医疗企业收购。路径2：IPO（科创板/港股）。路径3：持续经营分红。
